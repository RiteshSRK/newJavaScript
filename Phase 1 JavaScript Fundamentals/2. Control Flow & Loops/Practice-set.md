## Conditional Statements Practice Set
### Q1. Even or Odd

👉 Write a program to check if a given number is even or odd.

### Q2. Largest of Two Numbers

👉 Take two numbers and print which one is larger using if...else.

### Q3. Largest of Three Numbers

👉 Take three numbers and find the maximum using if...else if...else.

### Q4. Positive, Negative, or Zero

👉 Check whether a number is positive, negative, or zero.

### Q5. Grade System

👉 If marks are:

- 90+ → A+

- 75-89 → A

- 50-74 → B

- <50 → Fail

Use `if...else if...else`.

### Q6. Leap Year Check

👉 Write a program to check if a year is leap year or not.
(Hint: divisible by 4 but not 100, OR divisible by 400).

### Q7. Calculator (switch)

👉 Write a program that takes two numbers and an operator (+, -, *, /) and performs the calculation using switch.

### Q8. Days of the Week (switch)

👉 Input a number (1–7) and print the day of the week.

### Q9. Traffic Light System (switch)

👉 Input a color (red, yellow, green) and print action:

- red → "Stop"

- yellow → "Ready"

- green → "Go"

### Q10. Nested Login Check

👉 Write a program that asks for username and password.

- If username = "admin" and password = "1234", print Login Successful.

- Else show appropriate message.
